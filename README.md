# Gamified Micro-Skills Learning Platform 🎮📚

A web-based platform to teach **technical micro-skills** (SQL basics, Excel formulas, networking fundamentals) using **gamified learning**.  

## Features
- User authentication (register/login)  
- Browse & attempt micro-skill lessons  
- Gamified rewards (points, badges, streaks)  
- Progress tracking  

## Tech Stack
- Frontend: React + TailwindCSS  
- Backend: Node.js (Express)  
- Database: MySQL/PostgreSQL
