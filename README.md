Project Name

A gamified learning platform for technical micro-skills

Overview

This project is a launch-ready web application designed as part of our Final Year Project (FYP). The system provides a gamified learning experience for students to practice micro-skills through lessons, quizzes, rewards, and progress tracking.

Features (Planned)

User authentication (register/login)

Browse micro-skill catalog

Lessons and quizzes with immediate feedback

Gamification (points, badges, leaderboards)

Difficulty-based access (locked/unlocked content)

Payment gateway (for advanced levels)

Admin panel for lesson management

Tech Stack

Frontend: React (Next.js or plain React, TBD)

Backend: Node.js + Express

Database: PostgreSQL (or MySQL/MongoDB, TBD)

Hosting: Vercel / Heroku (for demo)

Version Control: Git + GitHub

Development Workflow

We’re following Agile (Scrum) with ~2-week sprints. Timeline includes:

Phase 0: Setup and planning

Phase 1: Core MVP

Phase 2: Feature completion

Phase 3: Stabilization & testing
